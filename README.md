# Master Minds Coaching — Website

Single-page website for Master Minds (MBA, Law, CUET, IPM, BBA, Hotel Management and Study Abroad coaching).

- `index.html` — the whole site (HTML, CSS and JS in one file, hash-based routing such as `#/program/mba`).
- Every push to `main` is deployed automatically to GitHub Pages by `.github/workflows/deploy.yml`.
